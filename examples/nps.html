Compare search speed

Each build searches the same position for seconds, one after the other, and the table shows what its last info line reported: depth, nodes and nodes per second. The builds share one search; only the evaluation differs, so the differences in speed are the cost of the evaluation, and the depth reached shows what that buys back. The Beal build has no evaluation to speak of and no evaluation based pruning, so it searches more nodes to a lower depth.
